## Notes
- Pure-function shape (`measureLLMBaseline()`) means the same script can be invoked from the QA checklist, an ad-hoc admin endpoint, or another worker without re-implementing the aggregation
- CSV escape handles commas + quotes (one test specifically covers `O'Brien, "Best" College`)
- Sort order is `callCount desc` then `type asc` for stable, reproducible output across runs
- The script connects to MongoDB but doesn't import the BullMQ queue / app stack, so it's safe to run in any environment that has `MONGODB_URI` set
- Provider/model are NOT in the output (only `costInr`); the dev baseline's 56 calls were all Claude Sonnet 4.5
