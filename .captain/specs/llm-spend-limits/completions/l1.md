## Schema Decision Notes
- **Subdocument default `() => ({})`** chosen over inline `default: {}` so Mongoose actually instantiates the nested schema (which then applies its own field-level defaults). Without the parent default, `aiSpendLimits` is `undefined` on docs that omit it instead of `{ weeklyInr: 0, alertThresholdPct: 80 }`.
- **Nested `new Schema(..., { _id: false })`** used to suppress an auto-generated `_id` on the sub-doc — `aiSpendLimits` is a value object, not a separate entity.
- No new index needed: `aiSpendLimits` is read by `_id` (already indexed). Plan §2.3 / task brief explicitly call this out.
